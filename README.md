# COVID-19 Global Data Analysis & Visualization (EDA) 📊🦠

A comprehensive Exploratory Data Analysis (EDA) project analyzing global COVID-19 transmission trends, mortality rates, and recovery statistics using Python.

---

## 📌 Project Overview
The objective of this project is to explore and understand the historical trajectory of the COVID-19 pandemic across various countries. By cleaning and transforming time-series health data, this analysis highlights key patterns, spikes, and global impacts through clean visual dashboards.

---

## 🔍 Key Insights & Analysis Steps
- **Data Preprocessing & Cleaning:** Handled missing values, formatted dates/time-series data, and aggregated country-level metrics.
- **Global Spread Trends:** Tracked the growth curve of confirmed, recovered, and deceased cases over time.
- **Top Impacted Countries:** Identified and visualized the top nations by total case counts and active cases.
- **Mortality & Recovery Rates:** Computed and compared death-to-case and recovery-to-case ratios across regions.
- **Correlation & Patterns:** Analyzed distribution trends to detect peaks and significant inflection points during the pandemic.

---

## 🛠️ Tech Stack & Libraries
- **Language:** Python
- **Data Manipulation:** `pandas`, `numpy`
- **Data Visualization:** `matplotlib`, `seaborn`
- **Environment:** Jupyter Notebook
